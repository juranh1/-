# 美森苗木静态网站

这是一个纯 HTML + CSS + JavaScript 的苗木库存展示网站，不需要安装依赖，也不需要构建工具。

## 如何预览

直接用浏览器打开 `index.html`。

## 文件说明

- `index.html`：页面结构，包含导航、首屏、苗木库存、规格说明、图片预留、关于我们、联系我们。
- `src/styles.css`：页面样式，包含颜色、布局、库存列表、移动端卡片、按钮和 hover 状态。
- `src/main.js`：苗木库存数据、库存列表渲染、树种搜索功能、询价表单提交、本地询价记录读取。
- `admin.html`：最基础的询价后台页面，用来查看客户提交的询价记录。

## 后期如何增加树种

打开 `src/main.js`，找到 `stockData` 数组，复制一条数据并修改：

```js
{
  name: "树种名称",
  spec: "规格",
  quantity: "数量",
  note: "备注",
  level: "等级",
  image: "",
}
```

保存后刷新页面，库存区域会自动更新。

## 后期如何加图片

当前每条库存数据已经预留了 `image` 字段。后面可以把图片路径填进去，再扩展渲染逻辑显示真实图片。

## 后期可扩展方向

- 搜索：现在已经支持按树种名称搜索。
- 筛选：可给数据增加 `category` 字段，比如乔木、花灌木、常绿树。
- 分类：可按 `category` 分组显示。
- 详情页：可给每条数据增加 `id` 字段，再跳转到详情页。

## 在线询价说明

当前是纯静态项目，没有真正的服务器和数据库。

现在的询价记录先保存在浏览器 `localStorage` 里，适合本地演示业务流程：

1. 在首页“在线询价”提交表单。
2. 打开 `admin.html` 查看询价记录。
3. 在后台修改跟进状态。

注意：`localStorage` 只保存在当前浏览器里。换电脑、换浏览器、清理缓存后，记录可能看不到。

正式上线时，询价表单应该提交到后端接口，再由后端保存到数据库。`admin.html` 也应该改成从数据库读取真实记录。
